# Qamar Sites

Client sites built by Qamar Agency. One folder per client; each folder deploys as its own Netlify site (base directory = the folder).

- `little-bloom-room/` — The Little Bloom Room (bridal florist)
- `brewteaful-matcha/` — BrewTeaful Matcha (Chicago matcha bar)

`tools/` holds the converter that turns a Claude design canvas into a static page.
